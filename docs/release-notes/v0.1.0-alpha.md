# v0.1.0-alpha

Initial public preview of Balancelab Force Plate Tools.

## Included

- QTM-based force plate recording workflow.
- Offline trial loading and replay in the Analyze tab.
- COP trajectory, COP AP/ML, COP magnitude, and force signal visualization.
- Event marking based on time or signal conditions.
- Event-based analysis ranges.
- COP balance metric calculation.
- Excel export workflow with included files, descriptive statistics, analysis results, and events sheets.
- Synthetic demo CSV files for interface testing.
- User documentation for COP metric definitions and formulas.

## Notes

- This is an alpha release intended for preview, documentation, and workflow feedback.
- Synthetic example data is included for testing only.
- Real participant, patient, or experimental data is not included in this repository.
- Metric definitions are documented in [COP Metrics Guide](../cop-metrics-guide.md).
